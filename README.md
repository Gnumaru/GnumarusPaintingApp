# Gnumaru's Painting and Animation App

Live demo (GitHub Pages): https://gnumaru.github.io/GnumarusPaintingApp/

Source code: https://github.com/Gnumaru/GnumarusPaintingApp

Frontend-only single page web application for digital painting, pixel art, vector art and frame-by-frame animation, accelerated with WebGL2.

## Intended use

Classic desktop-like painting app (top menu bar, central canvas, bottom status bar) in the spirit of Photoshop, Krita and GIMP. Current version supports pixel-art sketching with a solid brush pencil and additive blending, contiguous-region bucket fill, two-click lines, cubic Bezier curves, multi-layer editing with per-layer transforms and per-channel locks, frame-by-frame animation over a layer x frame cell matrix, and directory-based projects.

## Features (v1)

- Desktop shell: File menu (New Project, Open Project, Save Project, Save project as, Import full project, Import SVG as layer, Import 3D Model as layer, Import image as layer, Export — every item also runs from the quick action palette and carries a tooltip), Edit menu (Undo/Redo, Settings, Reset Canvas Transform), Help menu (Shortcuts reference modal, Source code), pencil/bucket/eyedropper/line/curve/text/tile-brush/rectangular/elliptical/lasso/polygonal-lasso/color selection (selection in one drawer button)/destructive selection transform/non-destructive cell transform/non-destructive cell 3D rotation/destructive selection 3D rotation/loupe toolbar (paint, selection, destructive-transform and transform tools grouped in drawer buttons) with color picker, tool options bar below the menu bar, WebGL2 canvas, layers panel, status bar. `Ctrl+S` (`Cmd+S` on macOS) saves like File > Save Project (reuses the chosen folder, otherwise shows the OS folder picker).
- Pixel-art pencil (`B`): solid color, brush size as a min–max range 0.1..64 (pen pressure with size/size+opacity response interpolates min→max; without pressure the max always paints) with square/circle tip (circle default) plus anti-aliasing toggle in the tool options bar (integer-rounded when off, true float when on) with live mouse preview, nearest-neighbor display, wheel zoom + pan + rotation + flips. Loupe shortcut is `Z`. `E` toggles the eraser blend mode remembering the previous mode. Pixel perfect checkbox (always enabled; enabling snaps the size range to 1; takes effect at size 1 without anti-aliasing and with wrap off) keeps strokes exactly 1px thick. Wrap-around painting (off, left-right, up-down, both): repeat the texture infinitely while painting, paint outside to wrap around, neighbors shown for the active layer only. Brush pressure response (`none`/`size`/`opacity`/`size+opacity`) scales tablet strokes, with linear/soft/firm pressure curves for size and alpha. Painting tip modes beyond pixel: soft round (hardness falloff), grayscale image tips (imported PNG becomes a tintable alpha mask, auto-trimmed and archived as lossy JXL under OPFS `brushes/`) and dual-tip masking (second image mask multiplied over the primary dab; black blocks, white passes), dab spacing with fractional carry, per-dab flow, anchored paper grain (scale/strength), deterministic fuzzy jitter, pen tilt broadening, speed fade, tip rotation following the stroke, timed airbrush, pickup smudge/mixer (rate + wetness), and shareable JSON brush presets (built-ins + customs in localStorage, export/import) — all session-only in the pencil options, pixel mode untouched. Canvas symmetry (left-right/up-down/four-way, pencil only) lives in the always-visible editor options bar, with on-canvas axis lines and draggable handles outside the project area (drag moves the axis, Shift+click resets to the layer center). Stabilizer dropdown (`none` default without stabilization, `rope` leash with configurable 1..200 length, `follow` chase with typed 1..100 strength used as typed / 100) smooths strokes with a paint-focus dot plus rope-line overlay; stroke GPU uploads coalesce to one per animation frame during strokes.
- `Tab` hides/shows all interface chrome except the canvas.
- Bucket fill (`G`, also `F`): click fills the contiguous region of identical color with the current solid color (4-way flood fill, channel-lock aware, undoable). Eyedropper: click a pixel to copy the composited on-screen color into the paint color (hold `Ctrl` for temporary access, except while a selection tool is active). Selection tools (one drawer button, right-click to switch): rectangular drag, elliptical drag, freehand lasso draw, polygonal lasso click-commit, or color click (similarity + contiguous toggle); Shift+drag adds, Ctrl+Shift+drag intersects, Alt+Shift+drag subtracts; destructive selection transform edits it through anchors (resize, rotate, skew, flip, center-reset, auto-selects the whole texture when empty) plus feather/grow/shrink options, and Enter/Return/Esc merges it back. Cell Invert colors + Adjust colors… (brightness/contrast/posterize) via the cell menu. Onion skinning ghosts neighbor frames (matrix toggle + settings). Layers carry blend modes (Normal/Multiply/Screen/Darken/Lighten/Add). Color picker has saved swatches + recent colors. Non-destructive cell 3D rotation (`Y`): RGB trackball gizmo tilts the layer (rings/axes/handles, center resets rotations); destructive selection 3D rotation (`U`): same gizmo on the floating selection with foreshortening merge.
- Paint blend mode (shared by pencil/bucket/line/curve, selectable in each tool options bar): `normal` (default; straight-alpha source-over, so translucent repeats accumulate like Krita/Photoshop), `copy` (direct channel replacement), `eraser` (ignores RGB, subtracts paint alpha from pixel alpha down to 0; honors alpha locks). The Accumulate checkbox (on by default; off paints each stroke uniformly in one pass) lives in the pencil/line/curve options.
- Line tool: two clicks define a segment with width 0.1..64, square/circle ends and optional anti-aliasing (integer-rounded when off, true float when on) in the tool options bar, with mouse and rubber-band previews (shortcut `N`).
- Curve tool: press-drag-release sets start/end, then one click sets the start control point and a final click sets the end control point; live curve path, markers and handle lines while drawing; width 0.1..64, square/circle ends, anti-aliasing; Pixel perfect checkbox (always enabled; enabling snaps the width range to 1; takes effect at width 1 without anti-aliasing) keeps commits exactly 1px thick; undoable (shortcut `C`).
- Layers: add (`Insert` above current, or Add above/below from the row menu, auto names `L1, L2, ...`), delete, reorder, rename (panel double-click or matrix layer-name menu), visibility, opacity, right-click Merge Down (undoable, `Ctrl+E` on the active layer; composites over the below texture, or links the upper content/texture when the below cell has none; removes the layer only when its other-frame cells are empty/textureless, otherwise dissociates just the current cell) and Reset transform (rotation, flips, position, scale, skew back to identity); `PageUp`/`PageDown` and ArrowUp/Down select above/below with wrap-around plus `pos/total: name` toast (clicking a layer row, frame header or matrix cell also shows the toast); Shift+Up/Down moves the active layer with wraparound; `Delete` resets the current cell texture to transparent zeros (undoable); Non-destructive cell transform tool edits the active cell content (`Alt`+middle-click resets it); painting targets the active cell at the current frame (empty cells materialize on first use). Toast display time 0.5..2.0 s, default 1.0 s, in Edit > Settings Interface section. UI language in the same section (`System` default follows the browser language, or English / Português (Brasil)); the whole interface is translated, shortcuts never change.
- Pixel grid over the active layer (follows rotation/transform), hidden below 200 percent zoom; minimum zoom 200..6400 percent (default 1000 percent) and opacity 0..100 percent (default 100 percent), in Edit > Settings. Canvas rotation step 1..90 degrees, default 15, and minimum zoom 1..100 percent, default 1, in the same dialog.
- View shortcuts: `4`/`6` rotate by the step, `5` resets rotation, `0` resets the full canvas transform, `1` zooms 100%, `2` fits the rotated canvas on screen. Quick action palette (`Ctrl+Shift+P`): floating suggestion box over all actions, type to similarity-filter, Up/Down + Enter or click to run. Shift+Left-drag with pencil/line/curve resizes the tool live (horizontal only) with a real-time preview.
- Canvas background: checkerboard (default) or solid color in Edit > Settings; every setting has a per-setting reset arrow when non-default.
- Final preview window (floating, resizable) with internal zoom/pan (drag with left, right or middle button) of the flattened image as a single PNG export would look, painted over the same canvas background (solid color or matching checkerboard); updates live while painting and while transforming layers.
- Custom color picker: RGB/CMYK/HSV/HSL (default)/OKHSL/OKHSV/ARD with per-axis gradient bars and editable inputs; alpha axis on every model; always-visible HSV triangle (click/drag sets S/V, hue kept) inside a hue ring (click/drag sets only hue); no browser color picker is used anywhere.
- Animation matrix above the status bar: rows are layers, columns are frames (each frame has an editable name like layers, via double-click or Rename frame menu); each cell holds zero or one shareable cell content (texture, rich text, vector, 3D model or tilemap plus transform). New frames and new layers start empty (painting/transforming materializes content, or assign via `Select content`); cell menu has `Select content` (content picker modal with Text/Texture/Vector/3D/Tilemap/Empty kind badges and thumbnails), `Select text…` (text picker sharing entries across cells), plus `Edit text` and `Rasterize text` for text cells.
- Rich text contents (`X` text tool): click a cell to create or reopen a contenteditable editor dialog (bold/italic/underline, system fonts, size, color, paste sanitization, live preview, one undoable entry on OK, restore on Cancel); a cached 2x raster feeds render/export/transform/preview; paint tools are blocked on text cells with a rasterize-first hint; cell menu `Rasterize text` bakes a paintable texture; rich text storage (Edit > Settings) keeps documents `embedded` (inline, default), as raw `texts/*.html` files, or as single-file `texts/*.zip` archives (open sniffs each reference; switching modes and saving removes stale files). ArrowLeft/Right select frames, Shift+Left/Right moves them. Shift+click on a second frame header selects the inclusive range; right-clicking inside a multi-frame range offers Delete frames (confirm dialog with count and ranges).
- Vector graphic contents (no editing tools in v1): File > Import SVG as layer loads `.svg`/`.svgz` into the current cell — empty cells import in place (blank textures are reused), occupied cells get a new layer above with the import; unsupported content (filters, path effects, foreign objects, scripts, SMIL, external references) renders best-effort with a warning toast naming it; an async raster feeds render/export/transform/preview; paint tools are blocked on vector cells; vector storage (Edit > Settings) keeps sources `compressed` (single-file `svgs/*.zip`, default), raw `svgs/*.svg`, or `embedded` strings.
- 3D model contents (transform tool): File > Import 3D Model as layer loads three.js-native formats (glb/gltf/obj/stl/ply/fbx/dae/3mf/amf) into the current cell — empty cells import in place, occupied cells get a new layer above with the import; unreadable models and unsupported extensions show an error toast and import nothing; an async offscreen raster feeds render/export/transform/preview (shaded per-model `unlit` flat by default, or `lit` by the scene lights via the editor lighting selector); paint tools are blocked on model cells. Models always live as raw files under `3dmodels/<id>.<ext>`. The `modeltransform` toolbar tool (model drawer front, shared with the fly camera) orbits the model in place on the canvas (left-drag orbits with both axes inverted from the drag, wheel zooms, right-drag pans, `R` resets, `Enter` commits, `Esc` cancels, tool switch auto-commits); the committed orbit view persists per model with undo/redo and save/reopen. The `flycam` tool in the same drawer flies freely instead (drag looks with up looking up, WASD + QE moves, ZC orbits, JL turns, IK pitches, `R` resets, `Esc` exits, keys held keep flying until release; the fly pose is saved on the cell so re-entering resumes, surviving save/reopen).
- Tilemap contents + tile-brush tool: click an empty cell with the tile brush to create a tilemap (needs a staged tileset); click a tilemap cell to place the selected tile (right-click erases); any project texture works as tileset with rectangular tiles (default 16x16, wrap on overflow); per-tile flip H/V and 90° rotations on square tiles; live cursor preview, floating tiles window (draws the project canvas background), options bar with tileset picker (project textures only) and tile size; tilemaps stored inline in project.json.
- Shape tools (drawer, `D`/`H`/`J`/`K`): rectangle, ellipse, polygon and gradient with live previews; outline (configurable width/anti-aliasing) or filled; polygon commits with Enter/right-click; gradient fades paint to transparent (linear/radial, optional Bayer dithering); single undoable stroke each.
- Retouch tools (drawer): shading (`S`), blur (`I`), clone stamp (`A`, Alt+click source), recolor (`Q`) and jumble; left-drag strokes with one dab size, single undoable entry each.
- Crop tool (destructive drawer, no shortcut): drag a box to crop the current cell texture (undoable); refuses empty cells with a toast.
- Frame durations and playback: each frame may carry an explicit duration in fractional seconds via its header menu (Set/Clear, 0.001..60 s); frames without one use the project default (0.25 s, configurable in Edit > Settings Animation section with reset arrow, stored in `project.json`); play/stop transport in the matrix corner plays from the current frame, looping until stopped.
- Named animations: define `name,loop,frames` strings in the matrix-corner manage dialog (loop `none`/`forward`/`ping-pong`, 1-based frames, `A-B` ranges, `:ms` duration overrides); the corner dropdown highlights member columns and scopes playback to them; stored in `project.json`; Aseprite frame tags import as named animations.
- Layer resize: per-layer width/height 1..1024 via Resize button; expand fills transparent right and below, shrink crops right and below; undoable.
- Channel lock: per-layer R/G/B/A toggles; paint, clear and Merge Down write only unlocked channels. Example: alpha locked + paint keeps old alpha; green locked + cyan paint yields blue.
- Fit texture to size: layer and cell context menus open a modal with an alpha threshold (0..254, default from Settings, OK autofocused for Enter confirm); the texture is cropped to the smallest box with alpha above the threshold while keeping its apparent position; undoable.
- Project texture storage (Edit > Settings): project data file (zipped JSON `.gpa` default, plain JSON `.json` option) plus JPEG XL (default, lossless or lossy with 0..100 quality default 50), WebP (lossless or lossy with 0..100 quality default 50, same options), JPEG with 0..100 quality (default 95, alpha in a grayscale companion file) or PNG with 0..9 compression (default 9); rich text storage (`embedded` inline default, raw `texts/*.html`, or single-file `texts/*.zip` with the matching `.html` inside); 3D model lighting default (`unlit` flat colors default, or `lit` by the scene lights; only affects new imports and models touched by the 3D transform/fly tools); brush tips archive as lossy JXL with 0..100 quality (default 90); textures are encoded with the fastest encoder setting. Importing a full project runs the texture cleanup setting (none, fit transparent borders, crop to canvas, or crop+fit; default crop+fit); opening a saved native project always keeps textures exactly as stored, with no cleanup.
- Crop to canvas: layer and cell context menus crop the texture to what the canvas shows through the cell transform, keeping its apparent position; refuses fully-outside content; undoable.
- Resize to canvas: layer and cell context menus grow/shrink the texture to cover the whole canvas; Ctrl+Shift+arrows expand the current cell texture by a configurable step (default 16px); both keep the apparent position and are undoable.
- Textures named `t1`, `t2`, ... independent of layer names.
- Directory projects via the File System Access API (Chromium derivatives): `project.gpa` metadata by default (zipped JSON; plain `project.json` option, old plain folders still open) plus `textures/*.jxl` cell images (lossless JXL by default, `*.webp` when WebP storage is selected, configurable in Edit > Settings; legacy `*.png` projects open via automatic migration). Saving after a format change removes orphaned files (old texture extensions, JPEG alpha companions, stale data-file counterpart).
- Aseprite import via File > Import full project: `.ase`/`.aseprite` files load layers (groups flattened, tilemaps skipped), frames, frame durations and linked cels (shared cell contents); corrupt files are rejected with an error toast.
- Photoshop import via File > Import full project: `.psd` files load layers with opacity, visibility, offsets and names (flattened files load their composite image); blend modes, masks, groups and other unsupported data are ignored; corrupt files are rejected with an error toast.
- GIMP import via File > Import full project: `.xcf` files load layers with opacity, visibility, offsets, alpha-lock and names (groups flattened); blend modes, masks and other unsupported data are ignored; corrupt files are rejected with an error toast.
- Krita import via File > Import full project: `.kra`/`.krz` files load layers with opacity, visibility, offsets, channel-locks and names (groups flattened) plus keyframed animation (playback range becomes frames with hold, framerate sets the default frame duration); blend modes, masks, non-paint layers and other unsupported data are ignored; corrupt files are rejected with an error toast.
- WebGL2-only rendering with an explicit error message when unavailable. No WebGL1 fallback.

## Requirements

- A Chromium-derivative browser (File System Access API + WebGL2).
- Node.js 20+ and npm for building.

## Commands

- `npm run dev` — start the dev server.
- `npm run build` — type-check and build to `dist/`.
- `npm run test` — unit tests (Vitest).
- `npm run test:e2e` — end-to-end tests, whole suite (Playwright, headless Chromium).
- `npm run test:e2e:full` — alias for the whole end-to-end suite.
- `npm run deploy` — rebuild and copy `dist/` to `/var/www/html/GnumarusPaintingAndAnimationApp` (needs write access to `/var/www/html`; run with sudo if required).

## Hosting

The build uses relative asset URLs (`base: './'`), so the app works at the domain root (`http://localhost/`) and at any nested path (`http://localhost/my/web/app/path`).

## Tech stack

TypeScript (`strict`), Vite, Three.js (WebGL2 renderer), Lit (UI shell), Vitest, Playwright. All dependencies use permissive licenses (MIT / BSD / Apache-2.0). No GPL or proprietary licenses used.
