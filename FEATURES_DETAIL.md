# FEATURES_DETAIL — Gnumaru's Painting and Animation App (v1 MVP)

## 1. Desktop shell (`src/shell/GnumarusShell.ts`)

- `gnumarus-shell` Lit component: menu bar, tool options bar, toolbar, canvas host, animation matrix, status bar, New-canvas dialog, Resize-layer dialog, Settings dialog, Frame-rename dialog, Fit-texture dialog, Shortcuts dialog (`GNUMARUS_SHORTCUTS` grouped by File/History/Layers/Frames/Tools/View/Interface), canvas toast overlay.
- `Tab` toggles `uiHidden`, hiding menu/tool-options/toolbar/layers/matrix/status (`hidden` + `!important`) so only the canvas host remains; skipped inside text fields and open modal dialogs. `PageUp`/`PageDown` and ArrowUp/ArrowDown select the layer above/below with wrap-around and a `pos/total: name` toast (bottom = 1) that renders in the canvas host even when hidden (auto-hide configurable 0.5..2.0 s, default 1.0 s). ArrowLeft/ArrowRight select the previous/next frame with wraparound (`Frame i/n: name` toast). Clicking a layer row, frame header or matrix cell shows the same toast (cell changing both shows a combined message). Shift+Up/Shift+Down moves the active layer with wraparound; Shift+Left/Shift+Right moves the current frame with wraparound (selection follows). Arrow shortcuts stay out of text fields and of the color picker (its ring/triangle/bars keep their own keys). `Insert` adds a layer above the active one via `insertLayerAboveActive`; `Ctrl+E` merges the active layer down (same path as the context menu).

- Tool options bar (`data-testid="tool-options"`) sits immediately below the menu bar and follows the active tool: pencil shows brush size (number 0.1..64, clamped), brush shape (square/circle), anti-aliasing checkbox, Pixel perfect checkbox (disabled unless size 1 without AA), stabilizer dropdown (`none`/`rope`/`follow`, default `none`, plus rope length 1..200 default 20 only for rope and typed follow strength 1..100 default 20 used as typed / 100 only for follow) and blend mode; line shows line width (0.1..64), line shape (square/circle), anti-aliasing checkbox and blend mode; curve shows curve width (0.1..64), curve shape, anti-aliasing checkbox, Pixel perfect checkbox (disabled unless width 1 without AA) and blend mode; bucket shows blend mode; loupe and transform show exactly `the <tool-name> tool does not have any setting or helper button`.
- Animation matrix directly above the status bar: one row per layer (top-first like the layers panel), one column per frame; frame headers show editable frame names and select the current frame (double-click starts inline rename, Enter commits, Escape/blur cancels), cells select layer and frame; layer names open a right-click menu with Rename layer (dialog, like Rename frame); corner `+` adds a frame; frame headers have a context menu with Add frame before, Add frame after, Set frame duration, Rename frame and Remove frame (disabled for the last frame); each cell has a context menu with a single `Select content` item. Context menus open at the cursor and shift only by the measured overflow so they stay adjacent and fully inside the viewport. Canvas and preview refresh on every change.
- File menu items: New (width/height dialog, 1..1024, default 64x64), Open (directory picker), Save (writes to picked directory, reuses the handle afterwards, `title="Save (Ctrl+S)"`), Import (OS file picker for `.ase`/`.aseprite`, strict validation, success/error toasts). Global shortcut `Ctrl+S` (`Cmd+S` on macOS) calls the same save flow with `preventDefault` so the browser save dialog never opens; it works even when focus is in inputs.
- Help menu items: Shortcuts (opens a scrollable modal listing every keyboard shortcut grouped by File/History/Layers/Frames/Tools/View/Interface with what each one does).
- Edit menu items: Undo/Redo (image edits and layer resizes, with disabled state), Settings (canvas background checkerboard/solid, checkerboard mode image-space/screen-space, independent square width/height 1..128 default 16x16, colors A/B, pixel grid minimum zoom 200..6400 percent default 1000 percent, canvas rotation step 1..90 degrees default 15, toast display time 0.5..2.0 seconds default 1.0; every setting has a per-setting reset arrow shown only when non-default plus Reset defaults; applied live and persisted to `localStorage`) and Reset Canvas Transform (restores fit zoom, rotation, flips).
- Undo/redo: per-stroke bounding-box diffs plus resize before/after snapshots (max 100 entries), view transforms, settings and preview never recorded; shortcuts `Ctrl+Z` undo, `Ctrl+Y` or `Shift+Ctrl+Z` redo; history cleared on New/Open.
- Toolbar: pencil tool (solid brush), bucket fill tool (shortcut `F`, contiguous same-color region, monochrome line-bucket SVG glyph in the same style as the other tools), eyedropper tool (click copies the pixel color into the paint color; hold `Ctrl` for temporary access from any tool), line tool (two-click segment, `╲` glyph), curve tool (cubic Bezier, `〜` glyph), rectangular selection tool (shortcut `R`), destructive selection transform tool (shortcut `V`), loupe tool (zoom/rotate/flip, shortcut `Z`) and non-destructive cell transform tool (shortcut `T`, full anchor set), custom color picker popup plus a Final preview toggle; tool glyphs are scaled to fill their fixed-size buttons; every tool tooltip starts with its selection shortcut, then the tool name, then the explanation.
- Color: custom `gnumarus-color-picker` (`src/color/`) with models RGB, CMYK, HSV, HSL (default), OKHSL, OKHSV and ARD; every model has an alpha axis (0..255); hue axes 0..360; ARD Diagonal 0..360 and Ratio 0..255; other axes are percentages with one decimal; per-axis draggable gradient bars (own 0..max gradient, alpha bars fade) with keyboard support, editable numeric inputs, model selector and hex field; axis edits always re-render even when the output color is unchanged (no frozen sliders at zero value); no native `<input type="color">` remains; pencil, checker colors and solid background all use it; 8-digit hex carries alpha into the engine (`parseHexColor` extended).
- Color picker HSV section (always on top, independent of the selected model): 200px hue ring (`conic-gradient` red-at-top clockwise) with position indicator, 100x84 saturation/value triangle (white left edge, full-saturation right edge, black bottom edge) with position indicator; ring drags/keys change only hue (tracked value survives white/black), triangle drags/keys change S (x fraction) and V (1 - y fraction); alpha preserved; pure helpers (`hsvToRgbBytes`, `rgbBytesToHsv`, `trianglePointToSv`, `hsvWheelHue`) in `GnumarusColorModels`.
- Status bar shows tool, rotation degrees, flip state, hex color, cursor pixel coordinates, canvas dimensions, layer, frame (`Frame i/n: name`), zoom percentage, project name, modified marker, WebGL2/FS-API messages.
- All UI strings in American English.

## 2. WebGL2 canvas engine (`src/canvas/GnumarusCanvasEngine.ts`)

- Single `THREE.WebGLRenderer` (WebGL2-only, no fallback). Throws `GnumarusWebGlError` with a user-facing message when WebGL2 is unavailable. Red X (top edge) and green Y (left edge) axis lines with arrowheads plus a plain magenta border on the right/bottom edges (`THREE.LineSegments`, 1px, `frustumCulled: false`, above the pixel grid) overlay the current cell texture and follow its transform; hidden when the cell is empty.
- One `THREE.DataTexture` (`NearestFilter`, no mipmaps) per layer over CPU `Uint8ClampedArray` RGBA buffers; one plane per layer plus a configurable background plane (checkerboard or solid color, default checkerboard) plus a pixel grid overlay plane for the active layer; per-layer opacity and visibility; orthographic camera. The layer shader outputs `tex.rgb` with `alpha * opacity`; the grid shader draws 1 CSS pixel white lines at pixel boundaries of the active layer using the same project-space matrix; the background shader draws either the configurable transparency checker (image-space squares that pan/zoom with the canvas, or fixed screen-space squares; independent width/height, colors editable in Edit > Settings, persisted to `localStorage`) or a solid color (color editable in Edit > Settings), while the scene clear color (`#333333`) fills everything outside the drawable area.
- Pixel grid: visible only when `zoom >= gridMinZoom` and `zoom >= 200 percent`; threshold configurable 200..6400 percent, default 1000 percent; follows active layer size, position, rotation, flips and view transform via `writePlaneMatrix`.
- Final preview (`src/preview/GnumarusFinalRender.ts` + floating window): CPU composite of visible layers bottom-to-top in project space (`compositeFinalImage`), shown in a floating resizable window with internal zoom (25..6400 percent, default 400 percent, wheel/buttons) and pan (drag with left, right or middle mouse button, plus scroll); refreshes on pixels/layers/settings change and live on every non-destructive cell transform move or reset (`onTransformChanged`); renders the flattened image over the same canvas background (solid color fill, or the matching checkerboard with the configured sizes, colors and bottom-origin layout) as a single PNG export would look.
- View transform (view-only, buffer stays canonical): zoom 0.5x..64x, arbitrary rotation (clockwise-positive), horizontal/vertical mirror. The plane scale/rotation renders it; pointer mapping inverts the full transform so painting works while transformed. Shortcuts: `4`/`6` (main + numpad) rotate by the rotation step, `5` resets rotation, `1` sets 100% zoom, `2` fits the rotated bbox (`rotatedBounds`) on screen with centered pan.
- Tools: pencil (`B`, solid brush with size 0.1..64 and square/circle tip plus optional anti-aliasing, stamped through the current transform and layer transform, live tip preview, stabilizer `none`/`rope`/`follow` with focus dot `stabilizer-preview` plus dashed rope line `stabilizer-rope`), bucket fill (`G`, 4-way flood fill of the exact start-pixel RGBA region with the current color, channel-lock masked, no-op when the region already matches or all channels are locked), line (`N`, two-click segment with width 0.1..64, square butt caps or circle round caps, optional anti-aliasing, tip plus rubber-band previews), curve (`C`, press-drag-release endpoints plus two control clicks, cubic Bezier with width 0.1..64, square/circle ends, optional anti-aliasing, live path/handles/points preview, `Escape` cancels), rectangular selection (`R`, drag cuts a rect to a floating texture with marching ants), destructive selection transform (`V`, resize/rotate/skew/flip anchors plus move, Enter merges), loupe (`Z`) and non-destructive cell transform (`T`, same anchor set over the layer box: resize scales, skew shears, rotate turns, flip mirrors, center resets) — loupe left-drag zooms (up/right in, down/left out, anchored at drag start), right-drag rotates the canvas around the image center, middle-click flips the canvas X (Shift Y, Alt resets the canvas transform); non-destructive cell transform left-drag moves the active layer, right-drag rotates it around its own center, middle-click flips the layer X (Shift Y, Alt resets the layer transform).
- Floating selection: rectangular-selection release cuts cell pixels to a private floating buffer (locks ignored, undoable) shown on a live GL plane with a center-based affine placement (position, rotation, scale, skew, flipX/flipY); destructive selection transform edits it through anchors (rectangle resize handles, offset quarter-circle rotate handles, outer double-arrow skew handles shearing centered (dragged edge follows along the edge axis, opposite edge mirrors, perpendicular drags do nothing), flip double-arrow satellites around the center (above/below toggle flipX, left/right toggle flipY), circular-arrow center handle resetting to the as-cut snapshot) and merges it back with an inverse-map nearest resample (undoable). Floating state is home-attached and hidden off-home; undo/redo track the cut entry by stack depth; resize/merge/fit commit when home-involved, layer removal and project loads drop it.
- Paint blend mode (`normal`/`copy`/`eraser`, `parseBlendMode`, shared `blendMode` on engine and shell, `Blend mode:` status, select in pencil/bucket/line/curve options, `E` toggles eraser remembering the previous mode via `toggleEraserBlend`/`blendBeforeEraser`): `setPixel`/`drawLineSegment`/`drawCubicBezier`/`floodFill`/`blendPixelCoverage` thread the mode through; normal is straight-alpha source-over, copy writes channels directly, eraser subtracts paint alpha from pixel alpha honoring alpha locks; flood fill skips its same-color early exit except in copy mode.
- Zoom (wheel with zoom-to-cursor even while rotated, keyboard shortcuts `Ctrl+Alt+=` / `Ctrl+Alt++` zoom in and `Ctrl+Alt+-` zooms out), pan (middle-drag or Space+drag).
- Pencil strokes: width routed via `drawLineSegment` (anti-aliasing off rounds to the nearest integer min 1; on uses the real float; size 1 non-AA falls back to the exact 1px line; anti-aliased mode blends edge coverage honoring locks), pointer capture, out-of-bounds pixels skipped; with `accumulate` off the stroke builds a union coverage mask (`stampSegmentCoverage`/`drawCubicBezierCoverage`, max wins) and is applied once via `applyCoverageMask`+`repaintFromMask`; tip preview div (`data-testid="brush-preview"`) sized by `size * zoom` follows the mouse (square/circle via border-radius). With pencil pixel perfect active (size 1, no AA) each Bresenham candidate passes the per-stroke pixel-perfect filter (`paintPencilLine`, elbows restored from `strokeBase` or cleared from the mask) so strokes stay exactly 1px thick.
- Bucket fill: single click materializes an empty cell first, flood fills with an explicit visited mask plus stack (no recursion), pushes one region-diff `stroke` history entry tagged by texture (shared-cell safe), no entry when nothing changes.
- Line segments (`drawLineSegment`): float width 0.1..64 (`clampBrushSizeFloat`); aliased mode rounds to the nearest integer min 1 and stamps the brush tip (1px falls back to `drawPixelLine`); anti-aliased mode uses the real float and blends per-pixel coverage (Euclidean distance with round caps for circle, butt-cap rectangle with 1px feather for square; feathered dots), honoring channel locks; engine `commitLineTo` pushes one region-diff `stroke` entry; `Escape` cancels the armed start; SVG rubber-band preview (`data-testid="line-preview"`) from first click to cursor with width-mapped stroke and matching caps.
- Brush settings: `brushSize`/`lineWidth`/`curveWidth` floats 0.1..64 (`clampBrushSizeFloat`; `roundBrushSizeForAliased` for the non-AA path), `brushShape` square/circle (`parseBrushShape`, disk threshold `(size/2)^2 - 0.5` floored at 0), `pencilAntialias` on/off, stabilizer `none`/`rope`/`follow` (`parseStabilizerMode`, `ropeLength` 1..200 default 20 via `clampRopeLength`, typed `followStrength` 1..100 default 20 via `clampFollowStrength` and used as `typed / 100`; rope holds the focus within the leash and drags it at rope distance, follow chases with `pos + (target-pos)*strength` per move plus a `requestAnimationFrame` catch-up loop while drawing/hovering, aliased stabilized segments floored to match `toImagePixel`), shared `accumulate` flag (default on; off uses the union-mask path); line settings add `lineShape` and `lineAntialias`; curve settings add `curveShape` and `curveAntialias`; engine setters return false on no-op; shell options-bar inputs (min 0.1 step 0.1, `Accumulate` checkbox, stabilizer select + rope/strength numbers) apply live with status messages. Shift+Left-drag on pencil/line/curve resizes that tool live from horizontal movement only (20 screen px per unit, `GNUMARUS_SIZE_DRAG_PX_PER_UNIT`, clamped 0.1..64; tip preview resizes in real time; shell options + status follow via `onToolSizeChanged`); no painting starts.
- Cubic Bezier curves (`drawCubicBezier`): flatten to a polyline (16..200 chords by control-polygon length, Bernstein evaluation; aliased joints rounded to ints so Bresenham terminates) and draw each chord with `drawLineSegment`; engine `commitCurveTo` pushes one region-diff `stroke` entry; phases idle/dragging/awaitC1/awaitC2 with `getCurvePhase`/`cancelCurve`; SVG preview (`curve-preview` path, `curve-handle-a/b` lines, `curve-point-0..3` markers) shows path/handles/points and is hidden after commit/cancel. With curve pixel perfect active (width 1, no AA) the commit walks the same flattened order through the pixel-perfect filter (`walkCubicBezierPixels` + fresh stroke, elbows restored from the pre-commit snapshot) so joints stay 1px thin.
- `Delete` (no modifiers, outside editable fields detected via `composedPath` so shadow-DOM inputs are respected): `clearCurrentCellTexture` fills the current cell texture with zeros in all channels ignoring locks; no-op when the cell is empty or already transparent; undoable region-diff `stroke` entry; `Escape` cancels an armed line or curve.

## 3. Layers

- Layers panel (right dock): add (auto names `Layer 1, Layer 2, ...`), delete (never the last one), reorder up/down, rename (double-click, Enter/blur commits, Escape cancels), per-layer visibility checkbox, opacity slider, R/G/B/A channel lock toggles and Resize button with dialog, click to activate (shows `pos/total: name` toast); right-click a row for the context menu (Merge Down, disabled on the bottom layer, Add above, Add below, Reset transform back to identity, Fit texture to size for the layer's current-frame texture, Crop to canvas for the layer's current-frame cell); status bar shows active layer name and stack position plus the current frame; each row shows its current-frame pixel dimensions.
- Layer model: `{ id, name, visible, opacity, lockedChannels: { r, g, b, a } }` with stable filename-safe ids; bottom-to-top stack order. Pixels live in texture entries owned by layers (one texture per layer, shared by reference, named `Texture 1, Texture 2, ...` independent of layer names; `renameLayer` no longer renames textures); what a layer shows is resolved per frame (see Animation below), so panel dimensions reflect the current frame. Painting, clear, resize and undo/redo target texture data; structural ops (except resize/merge/stroke) are not undoable.
- Textures: unified `textureNameCounter` generates `Texture N` for every new texture (layer-owned and `texN`); load recomputes the counter from max `Texture N`; merge snapshot stores `textureName` and restores it on undo.
- Layer resize: `resizeLayer(id, w, h)` resizes the layer's own texture with `resizePixelBuffer` top-left preserve; expand fills transparent right and below, shrink crops right and below; 1..1024 clamped integers; same size is a no-op (views showing that texture everywhere update too); undoable via `resize` history entry tagged by texture.
- Channel lock semantics: `setPixel`, `drawPixelLine`, `clearPixelBuffer` and `compositePixelOver` write only unlocked channels. Alpha lock + paint keeps old alpha; green lock + cyan (`#00ffff`) paint yields blue; fully-locked paint is a no-op (still hit-tests in bounds, produces no history entry).
- Non-destructive cell transform tool (`T`, shortcut `T`): full anchor set over the active layer box sharing the destructive overlay (corner/edge resize scaling about the opposite edge with a 1px minimum, offset rotate arcs, outer skew arrows with centered mirror shear, flip satellites around the center, center reset to identity), plus legacy gestures (left-drag moves, right-drag rotates about the layer center, middle-click flips X, Shift+middle-click flips Y, Alt+middle-click resets); layer transforms now carry scaleX/scaleY/skewX/skewY (defaults 1/1/0/0, back-compat project parse, scale >=1px effective, skew clamped ±2); content transforms are view-independent and not undoable; acting on an empty cell materializes a content first.
- Rendering positions every plane from the same pure project-space math used for picking, so display and editing always agree.
- Merge Down composites the current frame's visible transformed pixels of the active cell content over the transformed texture of the below layer's current cell content (nearest sampling) using the upper layer's opacity, masked by the lower layer's `lockedChannels`, and is fully undoable. When the below cell has no usable texture, the upper cell's content (empty below cell) or its texture (textureless below content) is linked into the lower cell instead of compositing pixels. The merged layer is removed only when all of its cells in every other frame are empty or hold textureless contents; otherwise the layer is kept, only the current cell's content is dissociated (cell becomes empty) and other frames stay untouched (undo re-associates the dissociated cell, dissociates the linked lower cell and restores the texture link; redo re-applies; removal still restores the layer, its texture pixels, its cells and any detached content links); undo/redo resync panel and matrix via `onLayersChanged`.

## 4. Animation (`src/animation/GnumarusAnimationModel.ts`, engine, matrix UI)

- Data model: the project is a matrix of cells; rows are layers, columns are animation frames; each cell references zero or one cell content (empty cells render nothing, any number of cells may share one content with no limit).
- Cell content combines zero or one project texture with cell settings (position, rotation, flip_x, flipY). Textures are the layer pixel buffers (each layer owns exactly one) plus new empty project-sized textures created on demand.
- New frames and new layers start with all cells empty. Painting or transforming an empty cell materializes a content (and a new texture when missing) so single-frame workflows are unchanged; the `Select content` modal can also associate existing or new content. New layers keep their owned `Texture N` entry (unreferenced until used) so resize/save/undo keep working.
- Canvas, picking, grid, non-destructive cell transform tool, history and the final preview all resolve through the current frame with shared `Uint8ClampedArray` references (no copies); undo entries are tagged by texture owner so shared-cell edits undo correctly; merge and resize operate on resolved pixels and restore removed layers with their cells and detached content links.
- Matrix UI (`getAnimationMatrix`): rows top-first, columns per frame with `frameNames`, active cell outlined, current-frame column marked. Cell menu has `Select content` (content picker modal) and `Fit texture to size` (threshold modal, disabled without texture) and `Crop to canvas` (immediate, disabled without texture) items opening `contentPickerDialog` / `fitTextureDialog`: vertically scrolling grid (`picker-grid`) with `No content` first, `New content` second, then all contents alphabetically sorted with thumbnails (`img.picker-thumb` data URLs from texture buffers, placeholder for textureless). `New content` creates an empty content via `createEmptyContentForCell`, assigns it, then opens `texturePickerDialog`: `No texture` first, `New texture` second (via `createEmptyTexture` + `associateContentTexture`), then all textures alphabetically sorted with thumbnails. Selecting applies to the cell and closes the modal. Frame headers show names and switch the current frame (tooltip shows `Frame i/n: name — duration ms`, click shows `Frame i/n: name` toast); frame header menu: Add frame before, Add frame after, Set frame duration (dialog with Set/Clear), Rename frame (dialog) plus Remove frame (disabled for the last frame); inline rename via double-click (Enter/blur commits, Escape cancels); Add frame appends an empty column with auto name `Frame N`; Remove frame drops its cells and shifts higher frames down (names and durations shift the same way, undoable: no, like other structural ops).
- Durations and playback: explicit per-frame durations (`frameDurations` map in the engine, `GNUMARUS_DEFAULT_FRAME_DURATION_MS = 100`, clamp 1..60000 ms, `effectiveFrameDurationMs` falls back to the project default); project default editable in Settings Animation section with the standard reset arrow and persisted in `project.json` (`animation.defaultFrameDuration`, `animation.frameDurations` sorted by frame, legacy projects migrate to 100 ms with no explicit entries); play/stop transport button in the matrix corner starts from the currently selected frame via a `setTimeout` chain reading the effective duration fresh each tick and looping, manual frame selection moves the playhead while playing, New/Open stop playback.
- Save writes `textures/*.png` plus `project.json` with `frames`, `currentFrame`, `textures`, `contents` and sparse `cells`; legacy `cells/<layer>_frame<frame>.png` projects open via automatic migration to a single frame.

## 5. Pure logic modules (fully unit-tested)

- `src/canvas/GnumarusPixelBuffer.ts`: buffer create/clear/get/set, Bresenham line, brush stamp/line (`drawBrushStamp`/`drawBrushLine`, square full box, circle disk mask, `clampBrushSize` 1..64, `parseBrushShape`), segment line (`drawLineSegment` with width/shape/anti-aliasing), `floodFill` (4-way exact-RGBA region, channel-lock masked, visited mask + explicit stack), `findAlphaBoundingBox` (tight box of pixels with alpha above a threshold), `#rgb`/`#rrggbb` parsing, `GnumarusChannelLock` (`{ r, g, b, a }`), `parseChannelLock`, masked `setPixel`/`drawPixelLine`/`clearPixelBuffer`/`compositePixelOver`, `clampLayerDim` + `resizePixelBuffer` (top-left preserve, transparent expand, crop).

- `src/canvas/GnumarusSelectionTransform.ts`: floating placement affine math (forward/inverse/bbox/determinant, tie epsilon, skew clamp); `src/canvas/GnumarusPixelPerfect.ts`: per-stroke `GnumarusPixelPerfectStroke` filter (painted set + paint order with tombstones, revisit-always-paints, consecutive-duplicate suppression, recent-window (4) crossing exception, elbow eating via `drainRemoved`), `countPixelPerfectNeighbors`, `walkBresenhamLinePixels` (same walk as `drawPixelLine`) and `walkCubicBezierPixels` (same flatten as aliased `drawCubicBezier`).
- `src/canvas/GnumarusViewportMath.ts`: screen<->pixel mapping with pan/zoom/rotation/flip (exact inverses), zoom clamping, rotation normalization, `rotatedBounds` (axis-aligned bbox of a rotated image for fit zoom).
- `src/history/GnumarusHistory.ts`: bounding-box image diffs tagged by texture owner plus `resize` before/after snapshots, `fit` texture-crop snapshots (buffer plus affected content transforms) and merge records with a removed-layer flag plus dissociated cell (associate/dissociate cell callbacks), capped undo/redo stacks; merge snapshot carries `lockedChannels`, removed cells and detached content links.
- `src/animation/GnumarusAnimationModel.ts`: cell key plus pure per-frame resolution over layers/textures/contents/cells (shared buffer refs, no copies), plus `clampFrameDurationMs` and `effectiveFrameDurationMs` duration helpers, plus pure frame insert/move remaps (`parseAnimationCellKey`, `insertFrameCells`, `insertFrameDurations`, `swapFrameCells`, `swapFrameDurations`), plus frame-name helpers (`defaultFrameName`, `normalizeFrameName`, `ensureFrameNames`, `insertFrameNames`, `swapFrameNames`).
- `src/project/GnumarusProjectFormat.ts`: `project.json` build/serialize/strict-parse with `frames`, `currentFrame`, `defaultFrameDuration`, sorted `frameDurations`, `frameNames` (required, legacy migrates to defaults), `textures`, `contents` and sparse `cells` (plus automatic migration of legacy `cells/<layer>_frame<frame>.png` projects to one frame with the 100 ms default).
- `src/settings/GnumarusCheckerSettings.ts`: checkerboard settings parse/serialize/validate with legacy migration.
- `src/settings/GnumarusGridSettings.ts`: pixel grid minimum zoom parse/serialize/validate, clamp 200..6400 percent, default 1000 percent, `shouldShowPixelGrid` (never below 200 percent).
- `src/settings/GnumarusRotationSettings.ts`: canvas rotation step parse/serialize/validate, clamp 1..90 degrees, default 15.
- `src/settings/GnumarusToastSettings.ts`: toast display time parse/serialize/validate, clamp 0.5..2.0 seconds, default 1.0.
- `src/settings/GnumarusBackgroundSettings.ts`: canvas background mode checkerboard/solid plus solid color parse/serialize/validate, default checkerboard `#808080`.
- `src/color/GnumarusColorModels.ts`: RGB/CMYK/HSV/HSL/OKHSL/OKHSV/ARD conversions, axis metadata, gradient CSS, hex with alpha.
- `src/color/GnumarusColorPicker.ts`: `gnumarus-color-picker` Lit component (swatch + popup, model select, gradient bars with keyboard support, numeric + hex inputs, `gnumarus-color-change` event).
- `src/preview/GnumarusFinalRender.ts`: `compositeFinalImage` flattening visible layers with opacity and transform (precomputed trig), transparent background.

## 6. Project format and file access

- Directory layout: `project.json` (`{ app, version: 1, width, height, layers: [{ id, name, visible, opacity, lockedChannels }], animation: { frames, currentFrame, defaultFrameDuration, frameDurations, frameNames, textures: [{ id, name, width, height, file }], contents: [{ id, name, textureId, transform }], cells: [{ layer, frame, content }] } }`) plus `textures/*.png`.
- `src/project/GnumarusFileSystem.ts`: File System Access API wrappers with feature detection and Chromium-only messaging.
- Aseprite import (`src/project/GnumarusAseprite.ts`, spec-based strict parser, no aseprite code): canvas size, image layers (groups flattened, tilemaps skipped), visibility, header-gated opacity, frames with per-frame durations (header speed fallback), raw/zlib cels in RGBA/grayscale/indexed (progressive palette, transparent index on non-background layers), linked cels resolved into shared cell contents (link geometry splits sharing), cel opacity baked into alpha; blend modes, z-index (last cel wins), tags, slices, tilesets, user data, color profiles and cel-extra scaling ignored; corrupt files rejected with byte-offset errors; caps 4096px dims and 10000 frames; native `DecompressionStream`; content/texture picker dialogs render (and generate thumbnails) only while open so frame switches stay cheap.
- `src/project/GnumarusPngCodec.ts`: RGBA buffer <-> PNG Blob via 2D canvas (encode on save, `createImageBitmap` decode on open).
- Save writes all textures plus metadata; Open validates dimensions and references and rejects corrupt files; legacy single-frame `cells/<layer>_frame<frame>.png` projects migrate automatically.
