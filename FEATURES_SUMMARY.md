# FEATURES_SUMMARY — Gnumaru's Painting and Animation App (v1 MVP)

- Desktop app shell: top menu bar (File > New/Open/Save, Edit > Undo/Redo/Settings/Reset Canvas Transform), left toolbar, central canvas, right layers panel, bottom status bar.
- Pixel-art pencil (`B`): solid color, brush size 0.1..64 with square/circle tip plus anti-aliasing toggle in the tool options bar (integer-rounded when off, true float when on), live tip preview following the mouse, paint blend mode (normal/copy/eraser), Accumulate toggle for uniform non-accumulating strokes, stabilizer dropdown (`none` default, `rope` with configurable 1..200 rope length, `follow` with configurable 0.01..1.0 strength) with paint-focus dot plus rope-line overlay.
- Bucket fill (`G`): click fills the contiguous region of identical RGBA color with the current solid color (4-way, channel-lock aware, undoable); monochrome line-bucket toolbar glyph matching the other tools.
- Line tool: two clicks define a segment with width 0.1..64, square/circle ends and optional anti-aliasing (integer-rounded when off, true float when on); tip preview plus rubber-band preview; undoable; shortcut `N`.
- Curve tool: press-drag-release sets start/end, then one click sets the start control point and a final click sets the end control point; live curve path, control-point markers and thin handle lines while drawing (destroyed after commit/cancel); width 0.1..64, square/circle ends, anti-aliasing; undoable; shortcut `C`.
- Paint blend mode (shared by pencil/bucket/line/curve, selectable in each tool options bar): `normal` (default; straight-alpha source-over, so translucent repeats accumulate like Krita/Photoshop), `copy` (direct channel replacement), `eraser` (ignores RGB, subtracts paint alpha from pixel alpha down to 0; honors alpha locks). `E` toggles eraser on/off remembering the previous mode.
- Tool options bar immediately below the menu bar: pencil shows brush size/shape/anti-aliasing/stabilizer/blend; line and curve show width/shape/anti-aliasing/blend; bucket shows blend; loupe and transform show exactly `the <tool-name> tool does not have any setting or helper button`.
- Custom color picker (no browser picker): models RGB, CMYK, HSV, HSL (default), OKHSL, OKHSV (Oklab-based) and ARD; alpha axis on every model (0..255); hue axes 0..360; ARD Diagonal 0..360 and Ratio 0..255; every other axis is a percentage with one decimal. Each axis has a draggable gradient bar showing its own 0..max gradient plus an editable numeric input beside it. Always-visible HSV section on top: hue ring with draggable indicator plus saturation/value triangle (white left, full-saturation right, black bottom) with its own indicator; dragging either updates the live color in every model.
- Pixel grid over the active layer, following its transform; hidden below 200 percent zoom; minimum zoom configurable 200..6400 percent, default 1000 percent, in Edit > Settings.
- Canvas background: checkerboard (default, configurable) or solid color (configurable) in Edit > Settings.
- Settings with per-setting reset arrows shown only when non-default.
- Final preview: floating resizable window with internal zoom and any-button drag pan of the flattened PNG-like render.
- Animation matrix above the status bar: rows are project layers, columns are animation frames; each cell holds zero or one shareable cell content (texture plus transform settings). New frames start empty; cell menu creates/associates/dissociates contents and texture links.
- Frame durations and playback: each frame may carry an explicit duration in milliseconds (frame header menu, Set/Clear dialog, 1..60000 ms, empty means project default); project default 100 ms in Edit > Settings Animation section with per-setting reset arrow, stored in `project.json`; play/stop transport in the matrix corner starts from the currently selected frame, each frame shows for its own duration or the project default, looping until stopped.
- Layers: add (`Insert` above current), delete, reorder, rename, visibility, opacity, right-click Merge Down (undoable, `Ctrl+E` on the active layer); `PageUp`/`PageDown` select above/below with wrap-around plus `pos/total: name` toast; `Delete` resets the current cell texture to transparent zeros in all channels (ignoring locks, undoable); Transform tool edits the active cell content; painting and clear target the active cell content at the current frame (empty cells materialize on first use). `Tab` hides all chrome except the canvas.
- Layer resize: per-layer width/height 1..1024 via Resize button + dialog; expand fills transparent right and below, shrink crops right and below, top-left preserved; undoable.
- Channel lock: per-layer R/G/B/A lock toggles; paint, clear and Merge Down write only unlocked channels (locked channels keep old values).
- Undo/redo for image edits and layer resizes (`Ctrl+Z` / `Ctrl+Y`), region-based history tagged per texture.
- Project directory holds `project.json` (layers, frames, contents, textures, cells) plus `textures/*.png` (legacy `cells/*.png` opens via automatic migration).
- WebGL2-only canvas (Three.js) with nearest-neighbor scaling, zoom, rotation + mirror view transform, and pan.
- Toolbar with pencil (`B`), bucket fill (`G`), line, curve and loupe (zoom/rotate/flip, shortcut `Z`) tools.
- Tool options bar below the menu bar: pencil exposes brush size (0.1..64), shape, anti-aliasing, stabilizer (`none`/`rope` + rope length 1..200/`follow` + strength 0.01..1.0) and blend; line/curve expose width (0.1..64), shape, anti-aliasing and blend; bucket exposes blend; loupe/transform show an empty-state label.
- Configurable transparency checkerboard: image-space or screen-space, independent width/height (default 16x16, asymmetric like 8x16 supported), two colors, persisted in the browser.
- Directory projects over File System Access API: `project.json` + `textures/*.png`. File > Save reuses the chosen folder; `Ctrl+S` (`Cmd+S` on macOS) triggers the same save (picker only when no folder chosen yet).
- Status bar: tool, color, cursor pixel, canvas size, layer, frame, zoom, rotation, flip state, project name, dirty flag, messages.
