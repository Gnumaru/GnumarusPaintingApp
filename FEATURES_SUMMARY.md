# FEATURES_SUMMARY — Gnumaru's Painting and Animation App (v1 MVP)

- Desktop app shell: top menu bar (File > New Project/Open Project/Save Project/Import/Import SVG/Export, Edit > Undo/Redo/Settings/Reset Canvas Transform, Help > Shortcuts/Source code), left toolbar (paint, selection, destructive-transform and transform tools grouped in drawer buttons), central canvas, right layers panel, bottom status bar. The Shortcuts dialog lists every keyboard shortcut grouped by area. Source code opens the GitHub project page in a new tab. Quick action palette (`Ctrl+Shift+P`): floating suggestion box listing every action alphabetically, similarity filtering as you type, Up/Down + Enter or click to run, Escape to close; unsatisfied action context shows an error toast explaining why. Batch actions: Fit All Textures to Size (same threshold dialog as Fit texture to size, applied to every texture), Crop All Cells to Canvas (canvas-visible crop for every cell, shared textures cropped sequentially) and Reload All Textures (re-reads every texture file from the saved project folder, skips memory-only/missing files with counts, single undo).
- Pixel-art pencil (`B`): solid color, brush size 0.1..64 with square/circle tip (circle default) plus anti-aliasing toggle in the tool options bar (integer-rounded when off, true float when on), live tip preview following the mouse, paint blend mode (normal/copy/eraser), Accumulate toggle for uniform non-accumulating strokes, Pixel perfect checkbox (only at size 1 without anti-aliasing and with wrap off) for exactly-1px lines, wrap-around painting (off, left-right, up-down, both) that repeats the texture infinitely and shows neighbors for the active layer only, brush pressure response (`none` default, `size`, `opacity`, `size+opacity`; mice always read full pressure) with linear/soft/firm pressure curves for size and alpha, stabilizer dropdown (`none` default, `rope` with configurable 1..200 rope length, `follow` with typed 1..100 strength used as typed / 100) with paint-focus dot plus rope-line overlay. Painting tip modes keep pixel mode untouched: soft round (hardness falloff), grayscale image tips (PNG import becomes a tintable alpha mask), dual-tip masking, dab spacing with fractional carry, per-dab flow, anchored paper grain (scale/strength), deterministic fuzzy jitter, pen tilt broadening, speed fade, tip rotation following the stroke, timed airbrush, pickup smudge/mixer (rate + wetness), shareable JSON brush presets (6 built-ins + customs in localStorage with export/import), dual tip as a second image mask multiplied over the primary dab (black blocks, white passes) — session-only in the pencil options, every setting with an explanatory tooltip. Canvas symmetry (left-right/up-down/four-way, pencil only) lives in the always-visible editor options bar, with on-canvas axis lines and draggable handles outside the project area (drag moves the axis, Shift+click resets to the layer center). Imported tips auto-trim transparent borders and archive as JXL under OPFS `brushes/`.
- Bucket fill (`G`): click fills the contiguous region of identical RGBA color with the current solid color (4-way, channel-lock aware, undoable); monochrome line-bucket toolbar glyph matching the other tools.
- Line tool: two clicks define a segment with width 0.1..64, square/circle ends and optional anti-aliasing (integer-rounded when off, true float when on); tip preview plus rubber-band preview; undoable; shortcut `N`.
- Curve tool: press-drag-release sets start/end, then one click sets the start control point and a final click sets the end control point; live curve path, control-point markers and thin handle lines while drawing (destroyed after commit/cancel); width 0.1..64, square/circle ends, anti-aliasing; Pixel perfect checkbox (only at width 1 without anti-aliasing) keeps commits exactly 1px thick; undoable; shortcut `C`.
- Paint blend mode (shared by pencil/bucket/line/curve, selectable in each tool options bar): `normal` (default; straight-alpha source-over, so translucent repeats accumulate like Krita/Photoshop), `copy` (direct channel replacement), `eraser` (ignores RGB, subtracts paint alpha from pixel alpha down to 0; honors alpha locks). `E` toggles eraser on/off remembering the previous mode.
- Editor options bar (always visible): wrap mode plus symmetry mode (off/left-right/up-down/four-way, pencil only).
- Tool options bar immediately below the menu bar: pencil shows brush size/shape/anti-aliasing/stabilizer/blend; line and curve show width/shape/anti-aliasing/blend; bucket shows blend; loupe and non-destructive cell transform show exactly `the <tool-name> tool does not have any setting or helper button`.
- Custom color picker (no browser picker): models RGB, CMYK, HSV, HSL (default), OKHSL, OKHSV (Oklab-based) and ARD; alpha axis on every model (0..255); hue axes 0..360; ARD Diagonal 0..360 and Ratio 0..255; every other axis is a percentage with one decimal. Each axis has a draggable gradient bar showing its own 0..max gradient plus an editable numeric input beside it. Always-visible HSV section on top: hue ring with draggable indicator plus saturation/value triangle (white left, full-saturation right, black bottom) with its own indicator; dragging either updates the live color in every model.
- Selection tools (one toolbar drawer, right-click to switch the front tool): rectangular (`R`), elliptical (`O`), freehand lasso (`L`), polygonal lasso (`P`) and color (`W`, similarity + contiguous toggle) selections cut masked floatings with true-shape marching ants; with a floating selection active, Shift+drag adds, Ctrl+Shift (Cmd+Shift)+drag intersects (empty clears), Alt+Shift+drag subtracts (disjoint no-op); destructive selection transform edits it through anchors (resize, rotate, skew, flip, center-reset) and Enter/Return/Esc (or Commit selection) merges it back. Cut and merge are undoable; undo/redo track the floating lifecycle.
- Non-destructive cell transform: same anchor set over the active layer box (resize scales, skew shears, rotate turns, flip mirrors, center resets to identity); layer transforms carry position, rotation, flips, scale and skew; legacy drags (move/rotate/flip) still work.
- Non-destructive cell 3D rotation (`Y`) and destructive selection 3D rotation (`U`): RGB trackball gizmo (axis rings solid-front/dashed-back, visible axis lines, single-axis handles, center resets only rotations); body drag tilts the sphere in the dragged direction; destructive variant auto-selects, tilts and merges with foreshortening; painting works on tilted layers.
- Vector graphic cell contents (no editing tools in v1): File > Import SVG (also a palette action) loads `.svg`/`.svgz` (svgz gunzipped, DOM-validated, scripts stripped) into the current cell — refused with an error toast unless the cell is empty or holds an empty content (blank textures are reused); unsupported content (filters, path effects, foreign objects, scripts, SMIL, external references) renders best-effort with a warning toast naming it; an async derived raster feeds render/export/transform/3D/preview/thumbnails; paint tools are blocked on vector cells with their own toast. Vector storage (Edit > Settings, default `compressed` single-file `svgs/*.zip`): raw `svgs/*.svg` files, zips, or `embedded` strings in project.json (open sniffs each reference; stale files removed on mode switch).
- Pixel grid over the active layer, following its transform; hidden below 200 percent zoom; minimum zoom configurable 200..6400 percent (default 1000 percent) and opacity 0..100 percent (default 100 percent), in Edit > Settings.
- Canvas view shortcuts: `4`/`6` (main + numpad) rotate by the configurable step, `5` resets rotation, `1` sets zoom 100%, `2` fits the rotated canvas on screen; rotation step 1..90 degrees, default 15, and minimum zoom 1..100 percent, default 1, in Edit > Settings.
- Shift+Left-drag with pencil/line/curve resizes the tool live from horizontal movement (right bigger, left smaller) with a real-time tip preview; no painting starts.
- Canvas background: checkerboard (default, configurable) or solid color (configurable) in Edit > Settings.
- Settings with per-setting reset arrows shown only when non-default. UI language selectable in Edit > Settings Interface section (`System` default follows the browser language, or English / Português (Brasil)); every interface text, status, toast and console message is translated, shortcuts never change.
- Final preview: floating resizable window with internal zoom and any-button drag pan of the flattened PNG-like render, painted over the same canvas background (solid color or matching checkerboard); updates live while painting and while transforming layers.
- Animation matrix above the status bar: rows are project layers, columns are animation frames; each cell holds zero or one shareable cell content (texture or rich text plus transform settings). New frames and new layers start empty (painting/transforming materializes content, or assign via `Select content`); cell menu has `Select content` (modal grid: No content, New content, New text, contents with Text/Texture/Empty kind badges and thumbnails), `Select text…` (text picker modal sharing entries across cells), `Edit text` and `Rasterize text` for text cells; New content opens a second modal to choose a texture (No texture, New texture, alphabetically sorted textures with thumbnails); frame menu adds frames before/after plus Set duration plus Rename frame plus Remove frame; Shift+click on a second frame header selects the inclusive range, and right-clicking inside a multi-frame range offers Delete frames (confirm dialog with count and ranges); layer names have a right-click menu with Rename layer; ArrowLeft/Right select frames, Shift+Left/Right moves them (wraparound). Frame headers show editable names.
- Rich text cell contents: `texts` pool beside `textures` (inline sanitized HTML subset, project format v3); text tool (`X`) clicks create/reopen a contenteditable editor dialog (bold/italic/underline, system font family/size, custom color picker, paste sanitization, live canvas preview, single undoable history entry on OK, restore on Cancel/Esc); render/flatten/export/transform/3D/preview/thumbnails use a cached 2x canvas raster injected as derived textures (never saved or listed); paint/bucket/line/curve/selection/Delete blocked on text cells with a rasterize-first toast; explicit `Rasterize text` bakes a texture content; UI in en + pt-BR.
- Frame durations and playback: each frame may carry an explicit duration in fractional seconds (frame header menu, Set/Clear dialog, 0.001..60 s, empty means project default); project default 0.25 s in Edit > Settings Animation section with per-setting reset arrow, stored in `project.json` v2 (v1 millisecond files migrate); play/stop transport in the matrix corner starts from the currently selected frame, each frame shows for its own duration or the project default, looping until stopped.
- Named animations: define `name,loop,frames` strings (loop `none`/`forward`/`ping-pong`, 1-based frames, `A-B` ranges, `:ms` per-frame or per-range overrides) in the matrix-corner manage dialog; the corner dropdown scopes playback and highlights member columns; `none` stops at the end, `forward` wraps, `ping-pong` bounces; stored in `project.json`; Aseprite frame tags import as named animations (reverse directions play backwards, play-once tags map to `none`).
- Frames have editable names like layers (double-click header inline rename, frame menu Rename frame dialog, 1..64 chars, persisted in `project.json` as `frameNames`); status bar shows `Frame i/n: name`, toasts show `Frame i/n: name`.
- Layers: add (`Insert` above current, or Add above/below from the row menu), delete, reorder, rename, visibility, opacity, right-click Merge Down (undoable, `Ctrl+E` on the active layer; composites over the below texture, or links the upper content/texture when the below cell has none; removes the layer only when its other-frame cells are empty/textureless, otherwise dissociates just the current cell) and Reset transform (rotation, flips and position back to identity); automatic names start at `L1` (`L1, L2, L3, ...`); `PageUp`/`PageDown` and ArrowUp/Down select above/below with wrap-around plus `pos/total: name` toast; clicking a layer row, frame header or matrix cell also shows the same toast; Shift+Up/Down moves the active layer with wraparound; `Delete` resets the current cell texture to transparent zeros in all channels (ignoring locks, undoable); Non-destructive cell transform tool edits the active cell content; painting and clear target the active cell content at the current frame (empty cells materialize on first use). `Tab` hides all chrome except the canvas.
- Toast display time configurable 0.5..2.0 seconds (float, default 1.0) in Edit > Settings Interface section with per-setting reset arrow, persisted in the browser. UI language lives in the same section (`System` default follows the browser language with English fallback, or English / Português (Brasil)); the whole interface (menus, dialogs, tooltips, settings, matrix, color picker, action palette, status/toast/console messages) is translated, keyboard shortcuts never change.
- Fit texture default alpha threshold configurable 0..254 (integer, default 0) in Edit > Settings; project data file (zipped JSON `.gpa` default, plain JSON `.json` option) plus project texture storage format (JPEG XL default, WebP, JPEG with 0..100 quality default 95 plus a grayscale alpha companion file, or PNG with 0..9 compression level default 9; JXL/WebP lossless default or lossy with 0..100 quality default 50; brush tips archive as lossy JXL with 0..100 quality default 90) plus rich text storage (`embedded` inline default, raw `texts/*.html` files, or single-file `texts/*.zip` archives) also lives in Settings with per-setting reset arrows, persisted in the browser; seeds the Fit texture to size dialog. Opening a project or importing a file runs the texture cleanup setting (none, fit, crop, crop+fit; default crop+fit).
- Layer resize: per-layer width/height 1..1024 via Resize button + dialog; expand fills transparent right and below, shrink crops right and below, top-left preserved; undoable.
- Fit texture to size: layer and cell context menus open a modal with an alpha threshold field (integer 0..254, seeded from the "Fit texture default alpha threshold" setting, default 0); OK is autofocused so Enter confirms immediately; on OK the texture is cropped on all four sides to the smallest box containing pixels with alpha above the threshold, shifting referencing content transforms so pixels keep their apparent position; undoable.
- Crop to canvas: layer (current-frame cell) and cell context menus crop the texture to the canvas-visible region through the cell transform (position, rotation, flips, scale, skew, tilt), re-seating transforms so rendering is unchanged; refuses fully-outside content, no-ops inside content; undoable.
- Resize to canvas: layer and cell context menus crop excess and pad transparent pixels so the texture covers the whole canvas area through the cell transform, keeping rendering pixel-identical; refuses outside/degenerate/oversize content; undoable.
- Cell texture expand step configurable 1..1024 pixels (integer, default 16) in Edit > Settings Interface section with per-setting reset arrow, persisted in the browser; Ctrl+Shift+ArrowUp/Down/Left/Right expands the current cell texture toward that side with transparent black, re-seating the transform; undoable.
- Channel lock: per-layer R/G/B/A lock toggles; paint, clear and Merge Down write only unlocked channels (locked channels keep old values).
- Textures named `t1`, `t2`, ... (independent of layer names; renaming a layer no longer renames its texture).
- Undo/redo for image edits and layer resizes (`Ctrl+Z` / `Ctrl+Y`), region-based history tagged per texture.
- Project directory holds `project.gpa` by default (max-compression ZIP with a single identical `project.json` inside; plain `project.json` when the data-file setting selects it; the stale counterpart is removed on save; old plain-JSON folders still open) holding layers, frames, frameNames, contents, textures, texts, cells plus `textures/*.jxl` (lossless by default; `*.webp` when WebP storage is selected; legacy `textures/*.png` and `cells/*.png` open via automatic migration) plus `texts/*.html` or `texts/*.zip` when external text storage is selected (`embedded` documents by default; open sniffs each reference). Changing the texture, text-storage or data-file format and saving removes the orphaned files (old extensions, JPEG alpha companions, stale counterpart, unreferenced text files).
- Aseprite import (File > Import): `.ase`/`.aseprite` files load layers, frames, frame durations, linked cels and frame tags (as named animations); tilemaps, blend modes and other unsupported data are ignored; corrupt files show an error toast.
- Photoshop import (File > Import): `.psd` files load layers, per-layer opacity/visibility/offsets and names (8-bit RGB/grayscale/indexed, 16-bit downconverted, Raw/RLE/ZIP channels, flattened files via their composite image); blend modes, masks, groups, PSB and CMYK-style modes are ignored or rejected with reasons; corrupt files show an error toast.
- GIMP import (File > Import): `.xcf` files load layers, per-layer opacity (incl. float variant)/visibility/offsets/alpha-lock and names (8-bit RGB/RGBA/gray/gray+alpha/indexed/indexed+alpha with the image colormap, uncompressed/RLE tiles, groups flattened); blend modes, masks, channels, zlib/fractal compression, >8-bit precision and newer versions are ignored or rejected with reasons; corrupt files show an error toast.
- Krita import (File > Import): `.kra`/`.krz` files load layers, per-layer opacity/visibility/offsets/channel-locks and names (8-bit RGBA/gray+alpha tiles, raw/LZF, groups flattened) plus keyframed animation (playback range maps to frames with hold, per-keyframe offsets, framerate sets the default frame duration); blend modes, masks, non-paint layers, animated opacity and >8-bit depths are ignored or rejected with reasons; corrupt files show an error toast.
- Frame export (File > Export): single-frame PNG/JPEG (plus AVIF/HEIC/HEIF only when the browser truly encodes them, verified by exact data-URL prefix since Chromium silently falls back to PNG), JPEG XL via the bundled WASM libjxl codec (lossless by default, optional 1-100 quality) or WebP via the bundled WASM libwebp codec (lossless by default, optional 0-100 quality; stills always go through WASM since canvas WebP has no lossless option), composited per frame without touching live state, JPEG flattens onto the canvas background; lossy formats take a quality setting (default 92, also used by sequences and spritesheets).
- Animated export (File > Export): named animation (or all frames) as an animated GIF via gifenc (per-frame 256-color palette, transparency preserved, play-once for `none` loops / repeat forever otherwise), as a single-file animated JXL via the WASM codec (lossless or 1-100 quality), as a single-file animated WebP via the WASM libwebp codec (lossless or 0-100 quality), or as an image sequence (PNG/JPEG/WebP plus detected formats, `name-001.ext` naming) saved through the directory picker with multi-download fallback.
- Spritesheet export (File > Export): checked animations (in definition order) plus all-frames strip plus manual `1,3-5` list, layouts single line, single column, one animation per line/column (ragged cells stay transparent), packed (columns from `floor(sqrt(N))`), fixed lines/columns with count input, or individual per-frame files; single sheets save as one still image, individual frames reuse the numbered sequence save. Any offered still format works, including JXL and WebP (WASM codecs).
- WebGL2-only canvas (Three.js) with nearest-neighbor scaling, zoom, rotation + mirror view transform, and pan. Red X (top edge) and green Y (left edge) axis lines with arrowheads plus a magenta border on the right/bottom edges overlay the current cell texture and follow its transform; hidden when the cell is empty.
- Toolbar with pencil (`B`), bucket fill (`G`, also `F`), eyedropper (click copies the composited on-screen color; hold `Ctrl` for temporary access), line (`N`), curve (`C`), text (`X`, click a cell to create or edit rich text), rectangular/elliptical/lasso/polygonal-lasso/color selection (drawer, `R`/`O`/`L`/`P`/`W`), destructive selection transform (`V`, anchors + Enter merges), non-destructive cell transform (`T`, anchors incl. 3D tilt), non-destructive cell 3D rotation (`Y`, trackball tilt), destructive selection 3D rotation (`U`, tilt + Enter merges) and loupe (zoom/rotate/flip, shortcut `Z`) tools.
- Tool options bar below the menu bar: pencil exposes brush size (0.1..64), shape, paint tip (pixel/soft/image + softness 0..100%, spacing 5..400%, flow 1..100%, fuzzy 0..100%, paper grain 0..100%/2..64px, image + dual tip import, size/alpha pressure curves linear/soft/firm), anti-aliasing, Pixel perfect (1px + no AA + pixel tip only), stabilizer (`none`/`rope` + rope length 1..200/`follow` + typed strength 1..100 used as typed / 100) and blend; curve exposes width (0.1..64), shape, anti-aliasing, Pixel perfect (1px + no AA only) and blend; line exposes width (0.1..64), shape, anti-aliasing and blend; bucket exposes blend; loupe/non-destructive cell transform show an empty-state label.
- Configurable transparency checkerboard: image-space or screen-space, independent width/height (default 16x16, asymmetric like 8x16 supported), two colors, persisted in the browser.
- Directory projects over File System Access API: `project.gpa` (zipped JSON default) or `project.json` (plain option). File > Save reuses the chosen folder; `Ctrl+S` (`Cmd+S` on macOS) triggers the same save (picker only when no folder chosen yet).
- Status bar: tool, color, cursor pixel, canvas size, layer, frame, zoom, rotation, flip state, project name, dirty flag, messages.
