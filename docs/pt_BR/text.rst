Texto
=====

A ferramenta **texto** solta um conteúdo rico editável na célula
ativa: família, tamanho, negrito/itálico/sublinhado, alinhamento e
cor, com desfazer/refazer por edição. O editor tem as abas Editar e HTML na barra de título: a aba HTML mostra o código somente leitura do painel visual e atualiza a cada edição. Clicar com o botão direito no código copia para a área de transferência com um aviso. O editor reabre pelo menu da
célula (**Editar texto**) para conteúdos existentes. O diálogo abre
logo acima do texto que edita (mantendo a pré-visualização visível),
arrasta por qualquer área livre, e o campo de tamanho confirma no texto
selecionado com Enter, no botão Definir ou ao perder o foco.

Pintar sobre o texto, ou **Rasterizar texto**, consolida os glifos em
pixels comuns (ainda uma entrada de desfazer). Conteúdos de texto
persistem nos projetos (modos raw ou zip), sobrevivem à reabertura e
exportam com selo; arquivos corrompidos relatam estado obsoleto em
vez de perder a célula.
