Configurações
=============

**Editar > Configurações** reúne todos os padrões num diálogo (cada
mudança vai para a barra de status, cada linha tem seta de
redefinição):

* Fundo do canvas (quadriculado cor/tamanho ou cor sólida).
* Grade de pixels (zoom mínimo, opacidade), passo de rotação, limites
  de zoom.
* Armazenamento de texturas (formato PNG/WebP/JXL, qualidade com
  perdas, nível PNG, qualidade JPEG).
* Qualidade JXL das pontas, limpeza de importação
  (nenhuma/ajustar/cortar/cortar+ajustar).
* Passo de expansão de célula, células vazias, limiar de ajuste ao
  tamanho.
* Duração padrão de quadro, tempo do aviso flutuante.
* Permitir alterações tocando, pacotes largos de spritesheet.
* Idioma (sistema/inglês/português) — o link do manual na Ajuda segue
  esta configuração.

**Redefinir padrões** restaura tudo de uma vez.
