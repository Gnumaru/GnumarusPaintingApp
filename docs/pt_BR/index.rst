Bem-vindo ao Manual do Gnumaru's Painting and Animation App
===========================================================

O *Gnumaru's Painting and Animation App* é uma aplicação web de página
única, só frontend, para pintura digital, pixel art, arte vetorial e
animação quadro a quadro, acelerada com WebGL2. Tudo roda no seu
navegador: os projetos ficam em pastas do seu disco (File System Access
API do Chromium) ou no armazenamento do navegador, e cada edição
permanece na sua máquina.
