Keyboard shortcuts
==================

Painting
--------

* ``B`` pencil, ``N`` line, ``C`` curve, ``G`` bucket, ``F`` bucket
  fill, ``T`` transform, ``Y`` 3D rotation, ``U`` selection 3D
* ``R`` rectangular selection, ``O`` ellipse, ``L`` lasso,
  ``P`` polygonal lasso, ``W`` color select
* ``X`` swap colors, ``E`` toggle eraser, hold ``Ctrl`` temporary
  eyedropper, hold ``Ctrl+Space`` loupe zoom
* ``Enter`` commit floating selection/transform, ``Esc`` cancel
* ``Shift+Left-drag`` live tool resize, ``Shift``/``Ctrl+Shift``/
  ``Alt+Shift`` selection modifiers

Canvas
------

* ``1`` zoom 100%, ``2`` fit rotated, ``0`` reset transform,
  ``5`` reset rotation, ``4``/``6`` rotate, ``M``/``Shift+M`` flips
* ``Ctrl+Alt+=``/``Ctrl+Alt+-`` zoom, wheel zoom at cursor, space-drag
  or middle-drag pan, right-drag loupe gestures

Actions
-------

* ``Ctrl+Z``/``Ctrl+Y`` undo/redo, ``Ctrl+X/C/V`` cut/copy/paste,
  ``Ctrl+Shift+C`` copy merged, ``Ctrl+E`` merge down
* ``Ctrl+S`` save, ``Ctrl+Shift+P`` action palette, ``0`` reset canvas
  transform, ``Tab`` hide interface, ``F`` bucket, ``Z`` loupe

The full list lives in **Help > Shortcuts** inside the app.
