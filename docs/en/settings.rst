Settings
========

**Edit > Settings** gathers every default in one dialog (each change
reports to the status bar, each row has a reset arrow):

* Canvas background (checkerboard colors/size or solid color).
* Pixel grid (minimum zoom, opacity), rotation step, zoom limits.
* Texture storage (format PNG/WebP/JXL, lossy quality, PNG level,
  JPEG quality).
* Brush tip JXL quality, import cleanup (none/fit/crop/crop+fit).
* Cell expand step, empty-cell handling, fit-to-size alpha threshold.
* Default frame duration, toast display time.
* Language (system/English/Português) — the manual link in Help
  follows this setting.

**Reset defaults** restores everything at once.
